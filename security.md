# Security Statement

## Intended Users

The intended users of this repository are students and instructors for the CSE 3000 course. The code and data are mainly used for coursework, assignments, and learning purposes.

## Security Risks

The repository does not contain highly sensitive personal information or confidential data. However, if someone with malicious intent gained access to the repository, they could modify the code or coursework files. There is also a risk of accidentally exposing passwords, API keys, or other sensitive information if they were added to the repository.

## Security Measures

I avoid storing passwords, API keys, or other sensitive information in the repository. I also review changes before committing and pushing them to GitHub. Since this repository is primarily for coursework and does not contain highly sensitive data or a production application, additional security measures such as CODEOWNERS files or strict pull request rules are not necessary at this time.
